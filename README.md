# Nest Notion Template Library

This library contains the initial operating templates for Nest.

## Template Groups

### Company

-   01 Weekly Review
-   02 Meeting Notes
-   03 Decision Record

### Product

-   04 PRD
-   05 User Research
-   06 Experiment
-   07 Feature Launch

### Engineering

-   08 Technical Design
-   09 ADR
-   10 API Specification
-   11 Security Review
-   12 Incident Report

### Operations

-   13 SOP
-   14 Property Verification

### General

-   15 Company Document
-   16 Risk Register

## Recommended Usage

Use the lightest template that matches the work.

-   Small task: use the Task database only.
-   Product feature: PRD -\> Tasks -\> Feature Launch.
-   Technical change: Technical Design -\> ADR when an architectural
    decision is made -\> Tasks.
-   Business hypothesis: Experiment -\> Decision Record.
-   Repeatable process: SOP.
-   Production failure: Incident Report.
-   Company policy or important reference: Company Document.
-   Material uncertainty: Risk Register.

## Notion Database Mapping

Recommended databases:
